Each reported claim maps to a file in `results/`. No value is transcribed by
hand: the tables and the claims check are generated by
`scripts/generate_paper_tables.py`, and both figures by
`scripts/make_figures.py`, all reading these files.

## Re-deriving the tables and figures

```bash
python scripts/generate_paper_tables.py --results-dir results
python scripts/make_figures.py --results-dir results --out-dir docs/figures
python scripts/plot_results.py --results-dir results --out-dir docs/figures
```

`make_figures.py` builds the two figures shown in the README. `plot_results.py`
builds per-dataset policy-value and ablation figures from any Phase 4 output; it
raises on a missing result file rather than drawing a zero, and labels a cell
that produced no usable value rather than filling one in.

`results/paper/claims_check.md` is produced by the same script. It ranks every
agent under every estimator, states for each of a fixed set of hypotheses
whether the results support it, and flags any estimate resting on a small
effective sample size. It is generated rather than written, so it reflects the
results as they are rather than as they were expected to be.

## Internal consistency checks

- Every exact policy value is recomputed through a second code path in
  `scripts/reference_policies.py`; the two agree to within 0.0007, the residual
  being argmax ties broken differently on CPU and GPU.
- `assert_reproduces_logged_rewards` checks that the ground-truth block
  reproduces the logged reward of every evaluation round, which is the only
  thing that would catch a mismatched user or item index.
- Cross-fitting folds partition *contexts*, not rounds, so no reward model
  scores a context it was fitted on.
- The bootstrap resamples contexts rather than rounds; resampling rounds on this
  block reports an interval roughly 58x too narrow.
